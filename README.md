# Agustina Sidorowicz — Portfolio

Sitio web personal de **Agustina Sidorowicz**, actriz de cine y teatro — Córdoba, Argentina.

🔗 **Ver el sitio:** https://TU-USUARIO.github.io/  <!-- reemplazar por la URL real una vez publicado -->

## Sobre el sitio

Portfolio de una sola página con presentación, reel, galería de fotos y trabajos
en cine, teatro, videoclips y publicidad. Bilingüe (español / inglés) y adaptado
a celular y computadora.

## Tecnología

- HTML, CSS y JavaScript vanilla — sin frameworks ni dependencias.
- Videos embebidos desde YouTube con carga diferida (miniatura + reproductor en modal).
- Imágenes optimizadas y tipografías de Google Fonts.
- Alojado en GitHub Pages.

## Correr en local

No hay paso de build. Alcanza con abrir `index.html` en el navegador o levantar
un servidor estático:

```bash
python -m http.server 8000
# luego abrir http://localhost:8000
```

## Estructura

```
├── index.html          # Página
├── style.css           # Estilos
├── script.js           # Interacciones: carrusel, lightbox, idioma ES/EN
└── assets/images/
    ├── heros/          # Fondos del hero
    ├── gallery/        # Galería de fotos
    └── reel-poster.jpg # Portada del reel
```
